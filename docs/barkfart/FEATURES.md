# Feature parity: the original, and what Barkfart does with each

Sources (2026-11-16): the original's bundled changelog strings (4.0.0 to
4.3.2) and UI strings; its public update posts and App Store listings; and the
MIT-licensed community format spec sticknodes-rs (formats only). Descriptions
are in our own words.

Rule: every feature of the original ships in Barkfart, without the Pro split
or ads. "Better" says how we improve it. M = milestone.

## Camera (asked for explicitly)

| Original | Barkfart | M |
|---|---|---|
| Per-frame camera: pan, zoom, rotate, tweened with the frames | Camera layer with x, y, zoom, rotation tracks; any easing per key | M3 core (done), M4 UI |
| Camera wobble: XY, rotation, scale, with intensity and speed | Wiggle modifier on any camera track, plus camera-shake presets (light, heavy, impact) | M3 core (done), M6 presets |
| Auto-camera | Camera keys generated by a "follow figure" helper, editable afterwards | M4 |
| Lock figure to camera (moves with the view, e.g. HUD) | Layer parenting to the camera layer | M5 |
| Copy/paste camera between frames | Universal copy/paste of keys | M4 |
| Camera grid-line patterns (thirds and similar) | Overlay guides, view-only | M4 |
| Vertical video toggle (Shorts/TikTok) | Canvas size presets (16:9, 9:16, 1:1, custom) | M4/M8 |
| Camera visible-settings only while playing | Camera frame shown as a dashed box in the editor; "view through camera" toggle | M4 |

## Animation and timeline

| Original | Barkfart | M |
|---|---|---|
| Frames as full snapshots; frame strip | Frame strip view over keyed tracks (posing keys all nodes) | M4 |
| Tweening on/off, number of tweened frames | Per-key interpolation (hold, linear, bezier) and easing presets | M3/M4 |
| Per-figure "tween mode" (linear or easing) on a frame | Per-key easing | M4 |
| "Floaty" node option (changes how stretchy nodes tween) | Easing presets on length tracks (overshoot, settle) | M4/M6 |
| Tween stickfigure colours (toggle) | Colour tracks always interpolate unless keys are HOLD | M3 (done) |
| Repeat a range of frames N times | Loop modifier, symbol loop, or "repeat range" key operation | M4 |
| Copy this frame plus N following | Box select plus copy/paste in the dope sheet | M4 |
| Onion skin, "visible in onion skin" per figure | Evaluator-driven onion skin (any time offsets, past and future colours) with a per-layer toggle | M4 |
| Loop playback; skip frames under lag to keep timing | Playback clock in seconds; drops frames, never drifts | M4 |
| Undo/redo | Command-based undo for every edit, gestures merged into one step | M4 |
| FPS setting | Project fps for playback and export; data is fps-independent | M3 (done) |

## Figures and creation mode

| Original | Barkfart | M |
|---|---|---|
| Node tree: drag to rotate, stretchy and static nodes | Same gestures; length and rotation tracks | M4 |
| Segment types: rounded segment, segment, circle, filled circle, ellipse, triangle, trapezoid, polygon, curved segment | All imported and drawn; shapes listed in the format spec | M3b/M4 |
| Per-segment colour, scale, thickness, gradients (sideways, reversed, half-circle) | Same, as tracks where animatable | M3b/M4 |
| Circle outline, hollow circles | Same | M3b |
| Polyfills (filled shapes through nodes), following curves | Polygon shapes with inline creation guidance, no blocking dialogs | M3b/M4 |
| Connectors (segments between two nodes) | Same | M3b/M4 |
| Smart-stretch, angle lock, drag lock | Same, with a live preview instead of an explainer window | M4 |
| Join figure to a node (holding, wearing) | Layer parent to a node (attach) | M5 |
| Figure scale, rotation, colour; lock figure movement | Layer transform and lock | M4/M5 |
| Push back / pull forward (layering), joined figures move together | Layer order in the layer panel; attached children follow | M5 |
| Copy/paste segment, segment + children, properties ("paste special") | One clipboard plus Paste Special | M4 |
| Creation-mode auto-save every 5 min with history | Autosave of everything (projects too), with history | M4 |
| Node styles (how nodes and lines are rendered) | Handle styles in View Options | M4 |
| Magnifier, lockable | Magnifier loupe while dragging | M4 |
| Show main nodes only / all nodes of active figure | Same view options | M4 |
| Arrow nudge below one pixel | Nudge buttons with fine mode | M4 |

## Objects

| Original | Barkfart | M |
|---|---|---|
| Movieclips (reusable looping animation objects) | Symbols: nest to any depth, own timeline, offset, speed, loop, recursion | M3 (core done), M5 |
| Sprites: import images, multiple at once, animated GIFs, skew/distort, remove background colour, negative scale (flip) | Sprite layers with full transform tracks; GIF import as symbol of frames; mesh skew | M5 |
| Skin-to-rig converter (game skins to figures) | Later; needs its own design | Stretch |

| Background image | Sprite layer at the bottom, locked | M5 |

## Effects (filters in the original)

| Original | Barkfart | M |
|---|---|---|
| Transparency | Layer opacity track | M3 (done) |
| Blur (with a motion-blur toggle), glow, drop shadow, saturation, hue shift, invert, pixelate, tint | Keyframeable effect stacks on any scope, plus the full M6 list | M6 |
| Filter quality setting, "may cause lag" | Reduced-quality preview, cached subtrees, full quality on export | M6 |
| "Better quality blur" on export | Always full quality on export | M6/M8 |

| Sounds attached to frames, volume per sound, built-in sound library | Audio layers with clips in time, volume and pan tracks, fades, trims, scrubbing | M7 |

## Export and files

| Original | Barkfart | M |
|---|---|---|
| GIF, MP4 (up to 1080p), PNG sequence, export size slider, transparency | Hardware MP4 at device max, GIF with palette/dither, PNG with alpha, sub-frame motion blur | M8 |
| Watermark (on in the free version) | Off by default; optional custom watermark | M8 |
| Save/open projects, local backups of overwritten saves, save reminder | Atomic saves, rolling backup, autosave | M3/M4 |
| Import/export stickfigures and movieclips; open Pivot .stk files | Import .nodes/.nodemc/.stknds; export .nodes; Pivot later | M3b-d, stretch |
| Website submit/browse (60k figures) | Not built in (no network). Files from the site import normally | Never (by policy) |

## Interface and app

| Original | Barkfart | M |
|---|---|---|
| Quick tools: floating or docked | Context panel near the selection, docked mode | M4 |
| View options (stage outline, filter toggle) | Same | M4 |
| Screen padding for notches | Safe-area aware layout | M4 |
| Haptics | Same, optional | M9 |
| Languages | English first, translatable strings | M9 |
| Welcome screens, sample projects, rate-us nags, Pro upsell | Sample projects only, no nags | M4 |
| Frame or node limits ("unlimited nodes" setting) | No artificial limits; budgets only guard runaway recursion | M3 (done) |
